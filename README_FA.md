# Planner Life OS 7.2

نسخه ۷.۲ ادامه مستقیم نسخه ۷.۱ است و اطلاعات فعلی را حذف نمی‌کند. این نسخه سه لایه اصلی «هدف حرفه‌ای، پروژه متصل و سیستم‌ساز شخصی» را به پلنر اضافه می‌کند.

## مهم‌ترین قابلیت‌های نسخه ۷.۲

### ۱) اهداف حرفه‌ای

- ثبت نامحدود هدف
- حداکثر ۷ هدف فعال
- حداکثر ۳ هدف تمرکز ۹۰روزه
- وضعیت‌های پیش‌نویس، فعال، تمرکز ۹۰روزه، در انتظار، متوقف‌شده، فعلاً نه، تکمیل‌شده و بایگانی‌شده
- اتصال هر هدف به یکی از حوزه‌های زندگی
- تعریف چرایی، نتیجه مطلوب، تاریخ شروع، مهلت و اهمیت
- تعریف گام‌های قابل تیک
- تعریف چند KPI با مقدار فعلی، مقدار هدف، واحد و وزن
- محاسبه خودکار پیشرفت ترکیبی بر اساس گام‌ها و KPIها
- انتقال اختیاری اهداف نسخه قبلی بدون حذف اطلاعات قدیمی

### ۲) حوزه‌های زندگی

هشت حوزه اولیه بر اساس نیازسنجی شخصی ایجاد شده‌اند:

1. برند شخصی و مرجعیت حرفه‌ای — ۱۷٪
2. کسب‌وکار، درآمد و ثروت — ۱۷٪
3. سلامت و انرژی — ۱۵٪
4. جایگاه سازمانی و اثرگذاری — ۱۴٪
5. علم، دکترا و اعتبار بین‌المللی — ۱۳٪
6. مهاجرت و آینده زندگی — ۱۰٪
7. خانواده، روابط و شبکه‌سازی — ۸٪
8. رشد فردی و مهارت‌ها — ۶٪

نام، وزن، فعال یا غیرفعال‌بودن و حوزه‌های سفارشی قابل مدیریت هستند. مجموع وزن حوزه‌های فعال هنگام ذخیره به ۱۰۰ نرمال می‌شود.

### ۳) پروژه‌های متصل به اهداف

- ثبت پروژه فقط با انتخاب هدف مادر
- نوع، وضعیت، خروجی نهایی و معیار موفقیت
- تاریخ شروع، مهلت، بودجه و افراد مرتبط
- سه روش محاسبه پیشرفت: دستی، از روی کارهای متصل یا ترکیبی
- امتیازدهی صفر تا پنج به آورده مالی، اعتباری، علمی، سازمانی و بین‌المللی
- ایجاد کار مرتبط از داخل کارت پروژه
- مشاهده همه کارهای متصل به هر پروژه
- قالب‌های آماده برای کتاب، مقاله، اختراع، EPT، آزمون جامع، مدیر HSE، Global Talent، دوره آموزشی، پروژه سازمانی و محتوا

### ۴) سیستم‌ساز شخصی

- ساخت سیستم توسط خود کاربر
- اتصال سیستم به هدف و در صورت نیاز پروژه
- انواع روتین، فرایندی، محرک‌محور و دوره‌ای
- تناوب دستی، روزانه، هفتگی، ماهانه یا پس از محرک
- تعریف زمان استاندارد، هدف پایبندی و KPI
- تعریف تعداد نامحدود مرحله و تغییر ترتیب آن‌ها
- شروع اجرای سیستم و ساخت خودکار کار مرحله اول
- پس از تکمیل هر مرحله، ساخت فوری کار مرحله بعد
- ثبت تاریخچه اجرای سیستم
- محاسبه پایبندی ۳۰روزه
- شناسایی گلوگاه پس از سه عقب‌افتادگی یک مرحله در ۳۰ روز

### ۵) اتصال فعالیت‌های روزانه

سه فیلد جدید به فرم فعالیت اضافه شده است:

- هدف مرتبط
- پروژه مرتبط
- سیستم مرتبط

بنابراین زنجیره زیر در برنامه قابل اجرا است:

`حوزه زندگی ← هدف ← پروژه ← سیستم ← مرحله سیستم ← فعالیت روزانه`

### ۶) داشبورد نسخه ۷.۲

در بالای داشبورد فعلی یک مرکز فرماندهی جدید اضافه شده است:

- تعداد اهداف فعال
- تعداد اهداف ۹۰روزه
- پروژه‌های فعال
- سیستم‌های فعال
- تعداد گلوگاه‌ها
- حلقه پیشرفت سه هدف ۹۰روزه
- دکمه سریع ساخت هدف، پروژه و سیستم

## حفاظت از اطلاعات نسخه قبلی

- کلید LocalStorage قبلی حفظ شده است.
- جدول Supabase قبلی تغییر نمی‌کند.
- هنگام ارتقا از ۷.۱ به ۷.۲ یک نسخه پشتیبان محلی ساخته می‌شود.
- داده‌های قبلی روزانه، هفتگی، ماهانه، کارها، عادت‌ها و اهداف قدیمی حفظ می‌شوند.
- «اهداف قبلی» به‌عنوان یک صفحه جداگانه باقی می‌ماند.
- انتقال اهداف قدیمی به ساختار جدید اختیاری است.
- ساختار داده ابری همچنان در همان ردیف کاربر نگهداری می‌شود.

## روش نصب روی GitHub Pages

1. در نسخه فعلی از بخش «پشتیبان» یک فایل JSON دانلود کنید.
2. فایل ZIP نسخه ۷.۲ را از حالت فشرده خارج کنید.
3. تمام فایل‌ها و پوشه `icons` را در ریشه Repository فعلی جایگزین کنید.
4. مسیر Repository و آدرس سایت را تغییر ندهید.
5. Commit را انجام دهید.
6. آدرس زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-2
```

7. در لپ‌تاپ یک‌بار `Ctrl + Shift + R` بزنید.
8. در آیفون، وب‌اپ را کامل ببندید و دوباره باز کنید. در صورت باقی‌ماندن نسخه قبلی، داده سایت GitHub Pages را از Safari پاک کنید و دوباره وارد شوید.

## Supabase

برای این نسخه نیاز به اجرای SQL جدید نیست. همان جدول `planner_states` و سیاست‌های امنیتی قبلی استفاده می‌شوند.

پس از ورود ابری، یک بار دکمه «آپلود لوکال به ابر» را بزنید تا آخرین اطلاعات دستگاه روی Supabase ثبت شود.

## فایل‌های جدید و تغییرکرده

- `v72.js` منطق اهداف، پروژه‌ها و سیستم‌ساز
- `v7.js` ارتقای نسخه داده به ۷.۲
- `styles.css` ظاهر صفحات و فرم‌های جدید
- `index.html` بارگذاری نسخه ۷.۲
- `sw.js` کش آفلاین جدید
- `manifest.webmanifest` آدرس شروع نسخه جدید

## تست‌های انجام‌شده

- بارگذاری نسخه و مهاجرت ساختار داده
- ایجاد هشت حوزه اولیه با مجموع وزن ۱۰۰
- ساخت هدف دارای گام و KPI و محاسبه پیشرفت ترکیبی
- ساخت پروژه متصل به هدف
- ساخت سیستم دارای چند مرحله
- شروع اجرای سیستم و ایجاد فعالیت مرحله اول
- تکمیل مرحله اول و ایجاد خودکار مرحله بعد
- نمایش منوهای جدید و حفظ صفحات قبلی

## ترتیب استفاده پیشنهادی

1. ابتدا حوزه‌های زندگی را بررسی کنید.
2. سه هدف ۹۰روزه را بسازید.
3. برای هر هدف، پروژه‌های اجرایی ایجاد کنید.
4. برای فعالیت‌های تکراری یا چندمرحله‌ای، سیستم تعریف کنید.
5. کارهای روزانه را به هدف، پروژه یا سیستم متصل کنید.
6. بعد از چند هفته، گلوگاه‌ها و درصد پایبندی را بررسی کنید.
