# Planner Life OS 7.5

نسخه ۷.۵ ادامه مستقیم نسخه ۷.۴ است و همه اطلاعات فعلی شامل اهداف، پروژه‌ها، سیستم‌ها، مرورها، امور مالی، وام‌ها، اقساط، عادت‌ها و کارها را حفظ می‌کند.

در این نسخه چهار قابلیت اصلی اضافه شده است:

1. ثبت سریع و ثبت صوتی فارسی
2. اعلان مرورگر و یادآوری هوشمند
3. گزارش خودکار هفتگی
4. اتصال امن به ربات خصوصی تلگرام از طریق Supabase Edge Function

---

## امکانات نسخه ۷.۵

### ثبت سریع مرکزی

- دکمه شناور «ثبت سریع» در تمام صفحات
- ذخیره مستقیم عنوان در Inbox، بدون بازشدن فرم‌های اضافی
- میانبر `Ctrl + K` در ویندوز و `Command + K` در مک
- دسترسی سریع به:
  - Inbox
  - ثبت فعالیت کامل
  - ثبت درآمد
  - ثبت هزینه

### ثبت صوتی فارسی

- استفاده از تشخیص گفتار مرورگر با زبان `fa-IR`
- تبدیل مستقیم صدای فارسی به متن
- امکان ویرایش متن پیش از ذخیره
- مسیر جایگزین «دیکته صفحه‌کلید» برای آیفون و مرورگرهایی که Speech Recognition را پشتیبانی نمی‌کنند

> عملکرد تشخیص صوت مستقیم به پشتیبانی مرورگر وابسته است. در آیفون، دیکته فارسی صفحه‌کلید همیشه به‌عنوان مسیر جایگزین در دسترس است.

### اعلان مرورگر

از صفحه «اعلان و اتوماسیون» می‌توان اعلان‌های زیر را فعال کرد:

- کارهای دارای ساعت و یادآور
- قسط یک روز قبل از سررسید
- هدفی که حداکثر سه روز تا مهلت آن باقی مانده است
- سیستم‌هایی که موعد اجرای آن‌ها رسیده است
- خلاصه مدیریتی روزانه
- گزارش خودکار جمعه

امکانات تنظیم اعلان:

- ساعت خلاصه روزانه
- ساعت گزارش جمعه
- بازه سکوت شبانه
- فعال یا غیرفعال‌کردن هر نوع هشدار
- تاریخچه اعلان‌های مرورگر و تلگرام

> اعلان‌های محلی زمانی بررسی می‌شوند که برنامه یا PWA باز شده باشد. برای اعلان روی آیفون، برنامه را از Safari به Home Screen اضافه کنید و اجازه اعلان را از داخل برنامه بدهید.

### گزارش خودکار هفتگی

گزارش هفتگی شامل این موارد است:

- درصد تحقق کارها
- تعداد کارهای انجام‌شده
- تعداد کارهای عقب‌افتاده
- اجرای سیستم‌ها
- پیشرفت اهداف ۹۰روزه
- میانگین انرژی
- امتیاز LEVEL UP
- تعداد هشدارهای بحرانی
- پیش‌بینی مالی ۳۰روزه
- بردها و تصمیم هفته آینده، در صورت ثبت مرور هفتگی

گزارش را می‌توان:

- کپی کرد
- به‌صورت اعلان مرورگر نمایش داد
- به تلگرام ارسال کرد

پس از ذخیره مرور هفتگی، گزارش همان هفته به‌صورت خودکار به‌روزرسانی می‌شود.

### ربات خصوصی تلگرام

توکن ربات داخل فایل‌های عمومی یا مرورگر ذخیره نمی‌شود. ارسال پیام از طریق Supabase Edge Function انجام می‌شود.

اعلان‌های قابل ارسال به تلگرام:

- خلاصه روزانه
- گزارش هفتگی
- هشدارهای بحرانی
- پیام آزمایشی

## نصب نسخه ۷.۵ روی GitHub Pages

1. در نسخه فعلی از بخش «پشتیبان» یک خروجی JSON بگیرید.
2. فایل ZIP نسخه ۷.۵ را باز کنید.
3. تمام فایل‌ها و پوشه `icons` را در ریشه همان Repository فعلی جایگزین کنید.
4. فایل‌ها و پوشه جدید `supabase/functions/planner-telegram` را نیز نگهداری کنید؛ این پوشه برای استقرار ربات تلگرام است و به اجرای GitHub Pages آسیبی نمی‌زند.
5. Commit را انجام دهید.
6. آدرس زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-5
```

7. در لپ‌تاپ یک‌بار `Ctrl + Shift + R` بزنید.
8. در آیفون، وب‌اپ را کامل ببندید و دوباره باز کنید.

برای قابلیت‌های محلی این نسخه، اجرای SQL جدید در Supabase لازم نیست.

## فعال‌سازی اعلان مرورگر

1. وارد منوی «اعلان و اتوماسیون» شوید.
2. روی «فعال‌سازی اعلان» بزنید.
3. اجازه مرورگر را تأیید کنید.
4. گزینه‌های موردنیاز را روشن کنید.
5. ساعت خلاصه روزانه و گزارش جمعه را تعیین کنید.
6. «ذخیره تنظیمات اعلان» را بزنید.
7. برای آزمایش، «بررسی اکنون» را انتخاب کنید.

### نکته آیفون

- برنامه باید از Safari به Home Screen اضافه شده باشد.
- اعلان Web App در نسخه‌های جدید iOS قابل استفاده است.
- اگر اعلان ظاهر نشد، از Settings آیفون، بخش Notifications، نام Planner Life OS را بررسی کنید.

## ساخت ربات خصوصی تلگرام

### مرحله ۱: ساخت ربات

1. در تلگرام وارد `@BotFather` شوید.
2. فرمان `/newbot` را ارسال کنید.
3. نام و Username ربات را انتخاب کنید.
4. توکن ربات را دریافت و در محل امن نگهداری کنید.
5. وارد صفحه ربات خود شوید و `/start` را ارسال کنید.

### مرحله ۲: پیدا کردن Chat ID

پس از ارسال `/start`، می‌توانید Chat ID عددی حساب خود را با یکی از ابزارهای معتبر نمایش Chat ID یا از پاسخ `getUpdates` ربات به دست آورید. Chat ID فقط یک عدد است و توکن ربات نیست.

### مرحله ۳: استقرار Edge Function

فایل آماده در این مسیر قرار دارد:

```text
supabase/functions/planner-telegram/index.ts
```

با Supabase CLI:

```bash
supabase login
supabase link --project-ref YOUR_PROJECT_REF
supabase secrets set TELEGRAM_BOT_TOKEN=YOUR_BOT_TOKEN
supabase functions deploy planner-telegram
```

توکن را فقط در Supabase Secrets قرار دهید و هرگز آن را در `supabase-config.js`، GitHub یا تنظیمات پلنر وارد نکنید.

### مرحله ۴: اتصال از داخل پلنر

1. داخل پلنر وارد حساب ابری شوید.
2. وارد «اعلان و اتوماسیون» شوید.
3. «فعال‌سازی اتصال تلگرام» را روشن کنید.
4. Chat ID را وارد کنید.
5. نام Edge Function را روی `planner-telegram` نگه دارید.
6. تنظیمات را ذخیره کنید.
7. «ارسال پیام آزمایشی» را بزنید.

## محدودیت فنی مهم

GitHub Pages یک میزبان استاتیک است. بنابراین اعلان مرورگر و ارسال خودکار تلگرام، بدون یک سرویس زمان‌بندی سمت سرور، هنگامی که برنامه کاملاً بسته باشد تضمین نمی‌شود. در نسخه ۷.۵:

- اعلان‌های مرورگر هنگام بازبودن یا فعال‌شدن PWA بررسی می‌شوند.
- تلگرام از داخل برنامه و هنگام اجرای بررسی‌های خودکار ارسال می‌شود.
- Edge Function زیرساخت امن ارسال را فراهم می‌کند.

برای ارسال کاملاً زمان‌بندی‌شده در زمان بسته‌بودن برنامه، در مرحله بعد می‌توان Supabase Cron و صف اعلان سرور را به همین زیرساخت اضافه کرد.
