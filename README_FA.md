# Planner Life for Soil 7.8 — تایم‌باکسینگ افقی و عمودی

این نسخه مستقیماً روی نسخه کامل **7.7** ساخته شده است؛ بنابراین پیام‌های سه‌گانه روزانه، نمودارهای دایره‌ای، داشبورد جدید، اهداف، پروژه‌ها، سیستم‌ها، وام‌ها و اقساط، اتصال تلگرام، Cron و همه اصلاحات قبلی حفظ شده‌اند.

## امکانات جدید تایم‌باکسینگ

در صفحه «روزانه» یک بخش حرفه‌ای تایم‌باکسینگ اضافه شده است:

- انتخاب بین **نمای افقی** و **نمای عمودی**
- ذخیره آخرین نمای انتخاب‌شده برای دفعات بعد
- پوشش کامل شبانه‌روز از ساعت `00:00` تا `23:59`
- چیدمان افقی راست‌به‌چپ؛ ساعت صفر از سمت راست آغاز می‌شود
- نمایش عمودی با ساعت‌ها در ستون سمت راست
- ثبت سریع فعالیت با کلیک روی هر بازه خالی
- پرشدن هر تایم‌باکس بر اساس درصد پیشرفت:
  - بخش انجام‌شده: سبز
  - بخش باقی‌مانده: قرمز
  - فعالیت عقب‌افتاده: حاشیه نارنجی
- نمایش زمان شروع، پایان، مدت و درصد پیشرفت داخل هر باکس
- جلوگیری از قرارگرفتن فعالیت‌های هم‌زمان روی یکدیگر
- نمایش جداگانه فعالیت‌های بدون ساعت
- خلاصه زمان برنامه‌ریزی‌شده، زمان تحقق‌یافته، زمان آزاد و تعداد تایم‌باکس‌ها
- سازگار با لپ‌تاپ، موبایل و PWA

## حفظ اطلاعات نسخه 7.7

کلید اصلی ذخیره اطلاعات تغییر نکرده است:

```text
planner-1405-pro-v1
```

هیچ فعالیت، هدف، پروژه، سیستم، مرور، وام، قسط، تنظیم تلگرام یا داده ابری حذف نمی‌شود. نسخه 7.8 فقط یک تنظیم جدید برای نوع نمایش تایم‌باکسینگ به اطلاعات موجود اضافه می‌کند.

## نصب در GitHub Pages

1. ابتدا از پلنر فعلی یک خروجی پشتیبان JSON بگیرید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. تمام فایل‌های داخل پوشه `planner-life-for-soil-v7-8` را در ریشه Repository فعلی `planner1` جایگزین کنید.
4. دقت کنید فایل جدید `v78.js` کنار `index.html` قرار گرفته باشد.
5. تغییرات را Commit کنید.
6. نشانی زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-8
```

7. در ویندوز `Ctrl + Shift + R` بزنید.
8. در آیفون، PWA را کامل ببندید و دوباره باز کنید. در صورت ماندن نسخه قدیمی، آیکون PWA را حذف و دوباره از Safari نصب کنید.

## روش استفاده

1. وارد صفحه «روزانه» شوید.
2. در کارت «تایم‌باکسینگ روزانه»، دکمه «نمای افقی» یا «نمای عمودی» را بزنید.
3. روی بازه خالی کلیک کنید تا فرم فعالیت با ساعت شروع و پایان پیشنهادی باز شود.
4. هنگام ویرایش فعالیت، «درصد پیشرفت» را افزایش دهید؛ بخش سبز تایم‌باکس بیشتر و بخش قرمز آن کمتر می‌شود.
5. با کلیک روی هر تایم‌باکس، فرم ویرایش همان فعالیت باز می‌شود.
