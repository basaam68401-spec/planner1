# Planner Life for Soil 7.6

نسخه ۷.۶ یک ارتقای مستقیم روی نسخه فعلی پلنر است. کلید ذخیره‌سازی اصلی، ساختار همگام‌سازی Supabase و اطلاعات قبلی تغییر نکرده‌اند؛ بنابراین کارها، اهداف حرفه‌ای، پروژه‌ها، سیستم‌ها، مرورها، عادت‌ها، وام‌ها، اقساط، تنظیمات تلگرام و داده‌های پنهان‌شده حفظ می‌شوند.

## تغییرات اصلی نسخه ۷.۶

### حذف KPI از رابط

- فیلدهای KPI از فرم هدف حرفه‌ای حذف شده‌اند.
- عنوان، مقدار فعلی، مقدار هدف و واحد KPI از سیستم‌ساز حذف شده‌اند.
- مدیریت KPI حوزه‌های چرخ زندگی حذف شده است.
- امتیاز چرخ زندگی از اهداف، پروژه‌ها، اجرای سیستم‌ها و فعالیت‌های تکمیل‌شده محاسبه می‌شود.
- فیلد «شاخص» از برنامه سالانه حذف شده و با «خروجی مورد انتظار» جایگزین شده است.
- اطلاعات KPI قبلی حذف نمی‌شوند؛ فقط دیگر در رابط نسخه ۷.۶ نمایش داده یا در محاسبات استفاده نمی‌شوند.

### اهداف

- آیتم «اهداف قبلی» از منو حذف شده است.
- بخش «اهداف حرفه‌ای» تنها بخش اصلی اهداف است.
- اهداف قدیمی منتقل‌شده در داده‌ها باقی می‌مانند و حذف نمی‌شوند.
- پیشرفت هدف از گام‌ها، پروژه‌های مرتبط و فعالیت‌های مرتبط محاسبه می‌شود.

### صفحه روزانه

- چهار نمودار دایره‌ای برای تحقق روز، باقی‌مانده، میانگین پیشرفت و عقب‌افتاده اضافه شده است.
- نمودار تحقق روز سبز است.
- نمودار باقی‌مانده قرمز است و با تکمیل فعالیت‌ها کاهش می‌یابد.
- نمودار میانگین پیشرفت آبی است.
- نمودار عقب‌افتاده نارنجی است.
- سه کار مهم با یک فیلد «مهم‌ترین کار امروز» جایگزین شده است.
- مقدار قبلی «کار مهم ۱» به‌صورت خودکار به مهم‌ترین کار امروز منتقل می‌شود.

### داشبورد

ترتیب جدید داشبورد:

1. مرکز هشدار
2. مرکز فرماندهی اجرایی
3. چرخ زندگی بزرگ
4. نقشه حرارتی ۹۰ روز اخیر
5. اهداف ۹۰روزه، سیستم‌ها، فعالیت‌های امروز و روند ۱۴روزه

مرکز فرماندهی اکنون مهم‌ترین کار امروز، تصمیم فوری، پیشرفت اهداف ۹۰روزه، سیستم‌های موعددار، پروژه‌های خارج از مهلت، تحقق امروز و LEVEL UP را نمایش می‌دهد.

### منو

ترتیب بخش‌های موردنظر به شکل زیر اصلاح شده است:

- ماهانه
- سالانه
- کارها

«مدیریت مالی» و «اهداف قبلی» از منو حذف شده‌اند. «وام و اقساط» همچنان فعال است.

### مدیریت مالی

- رابط مدیریت مالی، ثبت درآمد، ثبت هزینه، بودجه و گزارش مالی حذف شده است.
- بخش وام و اقساط باقی مانده است.
- اطلاعات مالی قبلی از LocalStorage یا Supabase پاک نمی‌شوند؛ فقط در رابط نسخه ۷.۶ نمایش داده نمی‌شوند.
- هشدار کسری نقدینگی و پیش‌بینی مالی از داشبورد و گزارش‌های جدید حذف شده‌اند.

### نام و PWA

نام برنامه، عنوان مرورگر، Manifest، Service Worker و اعلان‌ها به این نام تغییر کرده‌اند:

```text
Planner Life for Soil
```

## نصب روی GitHub Pages

1. ابتدا در پلنر فعلی از بخش «پشتیبان» یک فایل JSON بگیرید.
2. فایل ZIP نسخه ۷.۶ را از حالت فشرده خارج کنید.
3. تمام فایل‌ها و پوشه‌های داخل پوشه `planner-life-for-soil-v7-6` را در ریشه Repository فعلی `planner1` جایگزین کنید.
4. فایل `supabase-config.js` همین بسته بر اساس نسخه فعلی شماست. اگر قبلاً آن را تغییر داده‌اید، نسخه موجود در GitHub خودتان را نگه دارید.
5. Commit changes را بزنید و منتظر تکمیل GitHub Pages بمانید.
6. آدرس زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-6
```

7. در ویندوز یک بار `Ctrl + Shift + R` بزنید.
8. در آیفون، PWA را کامل ببندید و دوباره باز کنید. در صورت باقی‌ماندن نسخه قدیمی، آیکون قبلی را حذف و دوباره از Safari به Home Screen اضافه کنید.
9. یک بار از حساب ابری خارج و دوباره وارد شوید تا آخرین وضعیت Supabase دریافت شود.

## حفظ اطلاعات نسخه اصلی

نسخه ۷.۶ عمداً از همان کلید LocalStorage استفاده می‌کند:

```text
planner-1405-pro-v1
```

بنابراین نصب نسخه جدید یک فضای اطلاعاتی جدا نمی‌سازد. همچنین:

- آرایه‌های امور مالی حذف نمی‌شوند.
- اهداف نسخه قبلی حذف نمی‌شوند.
- KPIهای قبلی حذف نمی‌شوند.
- وام‌ها و اقساط حفظ می‌شوند.
- اطلاعات Telegram و اعلان‌ها حفظ می‌شوند.
- جدول Supabase و شناسه کاربر تغییر نمی‌کنند.

حذف‌شدن آیتم‌ها در این نسخه به معنی پنهان‌شدن آن‌ها از رابط است، نه پاک‌شدن داده‌ها.

## Supabase و تلگرام

برای تغییرات رابط نسخه ۷.۶ اجرای SQL جدید لازم نیست. تابع `planner-telegram` فعلی همچنان کار می‌کند.

اگر Supabase Cron را فعال کرده‌اید، نسخه هماهنگ تابع در این مسیر قرار دارد:

```text
supabase/functions/planner-cron/index.ts
```

برای هماهنگ‌شدن گزارش‌های سروری با حذف بخش مالی، کد همین فایل را در تابع `planner-cron` جایگزین و دوباره Deploy کنید. اجرای مجدد `cron_setup.sql` لازم نیست، مگر اینکه Cron را هنوز نصب نکرده باشید.
