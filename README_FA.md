# Planner Life OS 7.3

نسخه ۷.۳ روی نسخه ۷.۲ ساخته شده و اطلاعات قبلی را حذف نمی‌کند. این مرحله «مرکز فرماندهی زندگی»، چرخ زندگی، امتیاز LEVEL UP، مرورهای روزانه و هفتگی و گزارش‌های PDF را اضافه می‌کند.

## قابلیت‌های اصلی نسخه ۷.۳

### داشبورد مرکز فرماندهی

- امتیاز کلی LEVEL UP از ۱۰۰
- تحقق وزنی فعالیت‌های امروز
- میانگین پیشرفت سه هدف ۹۰روزه
- درصد پایبندی به سیستم‌های فعال
- تعداد هشدارهای بحرانی
- مرکز هشدار سبز، زرد و قرمز
- نمایش اهداف تمرکز، سیستم‌ها، کارهای امروز و نقشه حرارتی ۹۰روزه
- امکان جابه‌جایی کارت‌های داشبورد با Drag & Drop و ذخیره ترتیب

### چرخ زندگی

هشت حوزه قبلی حفظ می‌شوند. امتیاز هر حوزه به‌صورت خودکار از این داده‌ها محاسبه می‌شود:

1. KPIهای قابل تعریف توسط کاربر
2. پیشرفت اهداف متصل به حوزه
3. پایبندی سیستم‌های متصل
4. پیشرفت پروژه‌های متصل

اگر KPI تعریف شده باشد، وزن پیش‌فرض محاسبه حوزه:

- KPIها: ۶۰٪
- اهداف: ۲۵٪
- سیستم‌ها: ۱۵٪

اگر KPI تعریف نشده باشد:

- اهداف: ۶۰٪
- سیستم‌ها: ۲۵٪
- پروژه‌ها: ۱۵٪

امتیاز کلی LEVEL UP از مجموع وزنی امتیاز حوزه‌های فعال ساخته می‌شود.

### مرور روزانه

- مهم‌ترین برد روز
- علت اصلی کارهای ناتمام
- انرژی از ۱ تا ۵
- حال روحی از ۱ تا ۵
- درس روز
- یادداشت آزاد
- پیشنهاد خودکار کارهای مناسب برای فردا
- انتقال هر پیشنهاد فقط پس از تأیید کاربر

مرور روزانه هم در صفحه روزانه و هم در منوی «مرورها» در دسترس است.

### مرور هفتگی جمعه

گزارش خودکار هفته شامل:

- تحقق کارها
- تعداد انجام‌شده و عقب‌افتاده
- اجرای سیستم‌ها
- پیشرفت اهداف ۹۰روزه
- میانگین انرژی روزهای ثبت‌شده

پرسش‌های مرور:

- سه برد اصلی هفته
- مهم‌ترین علت عقب‌افتادگی
- سیستم نیازمند اصلاح
- مهم‌ترین تصمیم هفته آینده
- تأیید برنامه پیشنهادی هفته آینده

### گزارش‌ها

- گزارش شخصی PDF شامل LEVEL UP، چرخ زندگی، اهداف ۹۰روزه، سیستم‌ها و هفته جاری
- گزارش پروژه PDF شامل هدف مادر، وضعیت، پیشرفت، خروجی، معیار موفقیت، آورده‌ها و کارهای پروژه
- دکمه بالای برنامه از «خروجی PDF» به «گزارش PDF» تغییر کرده است.

## حفظ و مهاجرت اطلاعات

- کلید LocalStorage قبلی حفظ شده است.
- ساختارهای اهداف، پروژه‌ها، سیستم‌ها و فعالیت‌های نسخه ۷.۲ بدون تغییر باقی می‌مانند.
- `dailyReviews`، `weeklyReviews` و `levelUpHistory` به ساختار داده اضافه می‌شوند.
- امتیاز LEVEL UP روزانه در تاریخچه ثبت می‌شود.
- همگام‌سازی رکوردی برای مرورهای روزانه، مرورهای هفتگی و تاریخچه LEVEL UP فعال است.
- پیش از مهاجرت، نسخه پشتیبان محلی ساخته می‌شود.

## نصب روی GitHub Pages

1. در نسخه فعلی از بخش «پشتیبان»، یک خروجی JSON بگیرید.
2. فایل ZIP نسخه ۷.۳ را باز کنید.
3. همه فایل‌ها و پوشه `icons` را در ریشه همان Repository فعلی جایگزین کنید.
4. نام Repository و آدرس برنامه را تغییر ندهید تا اطلاعات LocalStorage همان دامنه قابل شناسایی بماند.
5. پس از Commit آدرس زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-3
```

6. در لپ‌تاپ یک‌بار `Ctrl + Shift + R` بزنید.
7. در آیفون وب‌اپ را کامل ببندید و دوباره باز کنید. در صورت باقی‌ماندن نسخه قبلی، داده سایت GitHub Pages را از Safari پاک کنید و دوباره وارد شوید.
