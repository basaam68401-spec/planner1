# Planner Life for Soil 7.7

این نسخه روی نسخه 7.6 ساخته شده و کلید اصلی داده‌ها را تغییر نمی‌دهد؛ بنابراین اطلاعات فعلی اهداف، پروژه‌ها، سیستم‌ها، کارها، مرورها، وام‌ها، اقساط، تنظیمات تلگرام و اطلاعات ابری حفظ می‌شوند.

## امکانات جدید

- نمایش سه پیام ثابت روزانه در بالای تمام صفحات:
  - انگیزه و حرکت
  - انضباط و کنترل ذهن با الهام از میاموتو موساشی، اکهارت توله، دون میگوئل روئیز و آدام گرانت
  - قدرت و تدبیر با الهام از کتاب ۴۸ قانون قدرت
- پیام‌ها بر اساس تاریخ روز انتخاب می‌شوند و در تمام صفحات همان روز ثابت‌اند.
- جملات، بازنویسی آزاد و الهام‌گرفته‌اند و نقل‌قول مستقیم نیستند.
- تبدیل کارت‌های آماری در هفتگی، ماهانه، سالانه، اهداف، پروژه‌ها، سیستم‌ها و سایر بخش‌ها به نمودار دایره‌ای.
- رنگ‌ها:
  - تحقق و وضعیت مثبت: سبز
  - باقی‌مانده: قرمز
  - عقب‌افتاده، گلوگاه و خارج از مسیر: نارنجی
  - میانگین پیشرفت، پایبندی و امتیازها: آبی
- بخش سالانه اکنون چهار شاخص همسان دارد: تحقق، باقی‌مانده، عقب‌افتاده و میانگین پیشرفت.

## حفظ اطلاعات نسخه قبلی

کلید ذخیره‌سازی همچنان همان مقدار زیر است:

```text
planner-1405-pro-v1
```

هیچ جدول یا داده‌ای پاک نمی‌شود. این نسخه فقط رابط و نحوه نمایش آمار را ارتقا می‌دهد.

## نصب در GitHub Pages

1. از نسخه فعلی یک بکاپ JSON بگیرید.
2. فایل ZIP را از حالت فشرده خارج کنید.
3. تمام فایل‌های داخل پوشه `planner-life-for-soil-v7-7` را در ریشه Repository فعلی `planner1` جایگزین کنید.
4. تغییرات را Commit کنید.
5. نشانی زیر را باز کنید:

```text
https://basaam68401-spec.github.io/planner1/?v=planner-v7-7
```

6. در ویندوز `Ctrl + Shift + R` بزنید.
7. در آیفون، PWA را کامل ببندید و دوباره باز کنید. اگر نسخه قدیمی باقی ماند، یک‌بار آیکون PWA را حذف و دوباره از Safari نصب کنید.
